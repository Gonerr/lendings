# ФОК на Кустодиева / ООО «КЕБИНВЕСТ»

Самостоятельный одностраничный PHP-сайт. Разместите содержимое этой папки в корне сайта с PHP 7.4+; локально можно запустить `php -S localhost:8000 -t Кебинвест`.

Реквизиты и контактный адрес меняются в массиве `$company` в начале `index.php`. Формы, телефон, аналитика, сторонние скрипты и внешние изображения отсутствуют. Единственный контакт на странице — `kebinvest1@yandex.ru`.

## Локальные изображения

Все три изображения находятся в `images/` и загружаются по относительным путям. Они носят иллюстративный характер: это **не фотографии помещений ФОКа на Кустодиева**.

| Файл | Происхождение |
| --- | --- |
| `images/pool.webp` | Фото Mariusz Smenzyk, [оригинал на Unsplash](https://unsplash.com/photos/an-indoor-swimming-pool-with-blue-water-xs9r8fPUats). [Лицензия Unsplash](https://unsplash.com/license) разрешает бесплатное коммерческое использование. Сохранённая локальная копия уменьшена для сайта. |
| `images/gym.webp` | Оригинальная фотореалистичная иллюстрация, созданная для этого сайта: пустой современный тренажёрный зал, дневной свет, без людей, логотипов и текста. |
| `images/sports-hall.webp` | Оригинальная фотореалистичная иллюстрация, созданная для этого сайта: пустой универсальный спортивный зал, дневной свет, без людей, логотипов и текста. |

После получения реальных фотографий комплекса с разрешением на публикацию замените соответствующие файлы и обновите подписи в `index.php`.
