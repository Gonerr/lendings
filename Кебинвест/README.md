# КЕБИНВЕСТ

Одностраничный PHP-лендинг ООО «КЕБИНВЕСТ», собственника коммерческих помещений в физкультурно-оздоровительном комплексе. Текущий арендатор помещений — «Спортлайн».

## Запуск

Разместите содержимое папки в корне сайта с поддержкой PHP 7.4+ и направьте запросы к `index.php`. Для локальной проверки:

```bash
php -S localhost:8000 -t Кебинвест
```

Страница не требует сборки, базы данных или внешнего API. Шрифт Google Fonts подключён как необязательное улучшение; при недоступности используются системные шрифты. Сайт не содержит формы, аналитики и встроенной карты. Кнопки связи открывают почтовый клиент или набор номера.

Контакты и реквизиты находятся в массиве `$company` в начале `index.php`. Перед публикацией проверьте данные и согласуйте формулировки о деятельности арендатора с компанией. Визуальная архитектурная композиция выполнена средствами CSS и не является фотографией объекта.
