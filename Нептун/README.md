# Нептун

Одностраничный лендинг физкультурно-оздоровительного комплекса ООО «Нептун» (Санкт-Петербург).

- React (JavaScript) + Vite
- без сервера: заявка открывает почтовый клиент через `mailto`
- адаптивная вёрстка, карта Яндекса, разделы «О комплексе», «Направления», «Пространство», «Контакты»

## Запуск

```bash
npm install
npm run dev
```

## Данные компании

Юридические реквизиты взяты из открытых сведений. Телефон в исходных данных отсутствовал, поэтому основной канал — заявка и почта `info@neptun-fok.ru` (её можно заменить в `src/data.js`).
