# ПРАЙМ — лендинг ФОК

Одностраничный сайт для ООО «ПРАЙМ» (физкультурно-оздоровительный комплекс).

## Запуск

```bash
cd Прайм
npm install
npm run dev
```

Сборка: `npm run build`, предпросмотр: `npm run preview`.

## Стек

- React 19
- Vite 8

## Разделы

- Hero со слайдером и формой обратного звонка
- Преимущества
- Оборудование (переключаемые вкладки)
- О компании
- Галерея зала
- Контакты с картой и формой обратного звонка

Форма обратного звонка открывает почтовый клиент (`mailto:`) — серверной части нет.
