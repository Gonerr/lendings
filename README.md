# Лендинги — PHP-версия

Ветка содержит готовые компактные версии сайтов для обычного PHP-хостинга.
Каждая папка является самостоятельным сайтом и загружается в корневую папку
своего домена целиком.

## Требования

- PHP 7.4 или новее;
- включённая стандартная функция `mail()` для отправки заявок;
- отдельный домен или отдельный корень сайта для каждой папки.

Точка входа каждого сайта — `index.php`. Формы отправляют JSON-запрос в
`contact.php`; база данных и Composer не требуются. В УСПС адрес получателя пока
не указан, поэтому существующая форма продолжает открывать почтовую программу
пользователя.
